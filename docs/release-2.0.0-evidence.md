## Secret scanning

`scripts/v2_phase9_secret_scan.py` runs as a blocking CI check (enforced by
commit `5c76168`). The gate requires `scanned=true` and zero verified findings;
`scanned=false` is treated as a failure. Known synthetic fixtures used by the
redaction tests are baselined in `docs/v2/phase9/secret-scan-baseline.json`.

gate. This release links to that evidence; it performs no new drill.
