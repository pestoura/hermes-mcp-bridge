## 1.0.0 — retry safety classification

### Added

- Canonical fail-closed classification of Hermes upstream operations for retry
  safety.
- Safe reads may be retried only for bounded transport errors and an explicit
  allow-list of transient HTTP status codes.
- Session creation, run creation and stop requests are classified as ambiguous
  mutations and can never be automatically replayed.
- SSE event streams remain outside generic request retry; recovery continues by
  the existing polling fallback.

### Operational posture

- `BRIDGE_RETRY_ENABLED=false` remains the default.
- `BRIDGE_CIRCUIT_ENABLED=false` remains the default.
- This increment changes no production behavior and performs no deployment.
